# UCAS Conflict Demo Excel Files

Các file này được tạo từ format chuẩn của `ucas_hk2_timetable_import.xlsx`.

Lưu ý: mã phòng ưu tiên dùng `classroom_code` trong DB, ví dụ `A-A101`, không dùng `A101` cho các phòng A101-A106. Riêng `B199` dùng đúng mã `B199` vì DB đang lưu classroom_code là `B199`.

Nên import từng file riêng để demo dễ đọc. File tổng hợp chỉ dùng cuối cùng.
